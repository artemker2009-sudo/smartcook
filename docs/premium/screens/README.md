иначе лимит не упереть без десятка генераций: `02-sheet-web.png`,
`03-sheet-ios.png`, а также `05`/`10`, где видно «из 1». После проверок
настройка возвращена на 3, это подтверждено чтением значения обратно.

проведённые случайным паролем Robokassa, заданным только для Preview.
