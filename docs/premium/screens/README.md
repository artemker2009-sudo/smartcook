**Шторка снята при настоящей настройке «3 подбора в неделю»**: лимит потрачен
честно, тремя запросами по слову из кэша блюд — расход OpenAI нулевой, а текст
на экране ровно тот, который увидят люди.

Экраны `05`, `07`, `08`, `09`, `10` сняты до смены прайса и показывают прежние
цены 49/390/990. Пересняты те, где цена видна и решает: `01`, `02`, `06`.

после проверок — в `premium_orders`, `premium_grants`, `user_premium` и
`podbor_usage` снова пусто.
