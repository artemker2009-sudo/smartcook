# App Store — ассеты и заметки

Материалы для публикации SmartCook в App Store. Пополняется по сессиям.

## icon-1024.png
Иконка приложения для App Store Connect.
- 1024×1024, PNG, **без альфа-канала**, sRGB, без скруглений (Apple скруглит сам).
- Источник: брендовая аватарка (белый колпак на зелёном градиенте), 2048×2048.
- Сгенерирована: `sips -z 1024 1024` + встроен профиль sRGB.

## Осталось на сессию 5 (после установки Xcode)
- Скриншоты iPhone 6.7″ (1290×2796) — снять в симуляторе.
- Тексты: название, подзаголовок, описание, «Что нового».
- Страница `/support` (создать) и правки `/privacy` (см. план, риск R1/privacy).

## Новые цели Яндекс.Метрики (завести вручную в дашборде)
Код их уже шлёт, но в Метрике их пока нет:
- `account_deleted` — пользователь удалил аккаунт (R1).
- `feed_post_report` — жалоба на пост в ленте (R2).
- `feed_author_block` — «скрыть автора» в ленте (R2).

## Миграция БД, которую нужно прогнать ДО мержа R2
`supabase_community_post_reports.sql` — таблица жалоб (авто-скрытие поста после
3 жалоб + дедуп). Прогнать в Supabase SQL Editor. Без неё жалобы всё равно
доходят до Telegram (ручная модерация), но авто-скрытие не работает.
