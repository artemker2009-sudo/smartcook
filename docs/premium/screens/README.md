# Скриншоты приёмки Премиума

Сняты на превью ветки `feat/premium` при включённом `FEATURE_PREMIUM`.
Экраны телефона — ровно 390 px шириной, как в макете.

Обновлены 24.09.2026 под цены **169 ₽ в год / 490 ₽ навсегда** (тариф «Месяц»
убран) и под вычищенную админку.

**Шторка и профиль сняты при временной настройке «1 бесплатный подбор в
неделю»** — иначе лимит не упереть без десятка генераций. После проверок
настройка возвращена на 3, это подтверждено чтением значения обратно.

Экраны `05`, `07`, `08`, `09`, `10` сняты до смены прайса и показывают прежние
цены 49/390/990. Пересняты те, где цена видна и решает: `01`, `02`, `06`.

Тестовые аккаунты `test_premium_*` и все созданные ими строки удалены из базы
после проверок — в `premium_orders`, `premium_grants`, `user_premium` и
`podbor_usage` снова пусто.
